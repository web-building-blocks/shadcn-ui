
# Alert

An alert is a UI component that displays a callout message to capture user attention. It is commonly used to convey important information, warnings, errors, or success messages in a visually distinct manner, often accompanied by an icon for added context.

<Docs> <API Reference> <Storybook> <Design Guideline> <Accessibility>

## Introduction

The Alert component in our UI library is designed to deliver clear and accessible notifications that inform users about the system’s current state or guide them through the application flow. The component supports variants such as `default`, `destructive`, `information`, `warning`, and `success`, each with its own unique animation and color scheme to ensure users can quickly recognize the nature of the message. With customizable elements like icons, titles, and descriptions, the Alert component adapts well to various use cases, including system notifications, form validations, and updates.

## Usage

To use the Alert component in your project, import it as follows:

```tsx
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";

<Alert>
  <Terminal className="h-4 w-4" />
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>
    You can add components and dependencies to your app using the CLI.
  </AlertDescription>
</Alert>
```

## Variants

### Default

The default Alert variant is a general-purpose notification with a neutral design. It is ideal for standard messages that don't require specific attention levels. This variant includes smooth entrance animations for a subtle and professional appearance.

<ComponentPreview name="alert-demo" title="Default Alert" description="An alert with an icon, title, and description." />

### Success

The Success Alert is styled with a green color scheme to convey successful operations, such as “Data saved” or “Upload completed.” This variant uses upward animation to capture user attention in a positive context.

<ComponentPreview name="alert-animation" title="Success Alert" description="An alert indicating success with an icon, title, and description." />

### Information

The Information Alert is a blue-colored variant designed to convey informational messages. With a left-to-right slide-in animation, it is ideal for updates or instructions that assist users without signaling urgency.

<ComponentPreview name="alert-animation" title="Information Alert" description="An alert for general information with an icon, title, and description." />

### Warning

The Warning Alert, highlighted with a yellow color scheme, is used to notify users about potential issues. This variant enters from the right side, immediately drawing attention to caution users about potential risks.

<ComponentPreview name="alert-animation" title="Warning Alert" description="An alert for warnings with an icon, title, and description." />

### Destructive

The Destructive Alert variant uses a red color scheme and a scaling animation to indicate critical issues or errors, such as “Delete failed” or “Action cannot be undone.” This variant is best suited for alerts that require immediate user attention to prevent significant issues.
